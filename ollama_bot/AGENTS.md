# 🤖 Discord Bot アプリケーション層 サブプロジェクト開発ガイドライン (AGENTS.md)

本ディレクトリ（`ollama_bot/`）は、**Discord APIとの入出力、UI層（スラッシュコマンド・ContextMenu・ボタン）、Presence同期、およびハーネスへの純粋なファサード**を担当するサブプロジェクトです。

---

## 🎯 担当範囲と責務
1. **Discord イベントハンドリングとライフサイクル**:
   - `on_message`, `on_interaction` などの Discord イベント受信とルーティング。
   - スラッシュコマンド（`/bot`, `/bot_start`, `/bot_stop` 等）およびコンテキストメニュー（上限5個）の登録・制御。
   - Botの起動・スタンバイ制御（管理者権限チェック `BOT_ADMIN_USER_IDS`）。
2. **Discord UI層と送信制御**:
   - メッセージ送信、タイピングインジケーター（Typing...）の制御、リアクション付与。
   - 優先度付き返答キュー（`_reply_queue`）によるメンション/返信の優先処理。
   - Discord Presence（活動ステータス・DND/オンライン）およびサーバーニックネーム同期。
3. **ハーネスへのファサード（委譲レイヤー）**:
   - 推論・行動ループ、メモリ抽出、ツール実行はすべて `harness/agent/` 配下の各モジュールへ委譲し、本レイヤーには推論ロジックを直接記述しないこと。

---

## 🚫 境界条件と禁止事項（最重要）
1. **【スコープ外ファイル編集の厳禁】**:
   - **自身が担当する `ollama_bot/` 配下のファイルのみを編集すること。**
   - 他サブプロジェクト（`harness/agent/` 配下の各フォルダ）のファイルを直接変更してはならない。
   - インターフェースや外部型の変更が必要な場合は、自己判断で書き換えず、ルートエージェント（トリアージ・アーキテクト）へエスカレーションすること。
2. **単一プロセス・独立Bot稼働の厳守**:
   - 同一トークンでの複数プロセス同時起動を絶対に禁止する。
   - コマンドツリーの同期（`tree.sync()`）は単一プロセスまたは共有Bio同期を利用し、多重実行してはならない。
3. **discord.py イベントハンドラの親クラス非存在メソッド呼び出し禁止**:
   - `commands.Bot` のサブクラスにおいて `await super().on_interaction(...)` のような親クラスに存在しないメソッドを呼び出して `AttributeError` を引き起こしてはならない。
4. **IGNORE_USER_IDS 指定ユーザーの全インタラクション遮断**:
   - `on_message` だけでなく、スラッシュコマンドやUIボタン・モーダル等の全インタラクションを最上流で完全遮断し、エフェメラル通知で利用不可を案内すること。
5. **人格・特定台詞のハードコード根絶**:
   - 特定キャラクター名や特定の口癖をコード内にハードコードせず、すべて `config_*.py` 駆動とすること。

## 🛠️ コーディング規約と検証手順
- **型安全性**: Python 3.11+ 型アノテーションを完全に付与し、`mypy` エラー0件を死守すること。
- **検証コマンド**:
  ```bash
  # 本サブプロジェクトの単体テスト
  PYTHONPATH=mock_libs:. pytest tests/test_ollama_chat_lifecycle.py tests/test_bot_lifecycle_commands.py
  # 型検査
  PYTHONPATH=mock_libs:. mypy --config-file mypy.ini ollama_bot
  ```
