# 🎮 Tier Game サブプロジェクト開発ガイドライン (GEMINI.md)

本ディレクトリ（`tier_game/`）は、**Discord上で行われるティア表パーティゲーム（お題生成、選択肢提示、プレイヤー予想、スコアリング、相性度診断、ティア表画像描画）**を担当する独立サブプロジェクトです。

詳細な開発規約・境界条件・検証コマンドは [AGENTS.md](file:///Users/Shadow/Documents/05%20%E9%96%8B%E7%99%BA/discord-ai-bot/tier_game/AGENTS.md) を参照してください。

### 🎯 主な責務
1. **データモデルとバリデーション (`models.py`)**: `TopicData`, `PlayerState`, `RoundResult`。お題・選択肢の厳格な検証（客観クイズ排除、性的・怨嗟表現排除、表記揺れ重複正規化、架空タイトル・ポエティック文排除、構造不揃い排除）。
2. **お題生成とプール管理 (`topics.py`)**: AIお題生成、プリセットフォールバック、MemoryStoreからの着想テーマ抽出（行動傾向・内省メモ除外、ハードコード禁止）、バックグラウンドプール（`TopicPool`）サイズ適正化と重複排除。
3. **ゲーム進行・セッション管理 (`session.py`)**: フェーズ遷移、提出受付、タイムアウト制御。
4. **Discord UI / コマンド (`views.py`, `cog.py`)**: スラッシュコマンド（`/tier_game` 等）、起動時プリフェッチ抑制（`TIER_GAME_PREFETCH_ON_STARTUP=False`）。
5. **スコアリングと描画 (`scoring.py`, `renderer.py`)**: スコア・相性度計算、Pillowによるティア表リザルト画像レンダリング。

### 🚫 境界条件と重要禁止事項
1. **スコープ外ファイル編集禁止**: `tier_game/` 外のファイルを直接編集しないこと。
2. **DBテーマ抽出における対話分析・人物行動傾向メモ混入禁止**: `memories` テーブルからの記憶抽出時、対話傾向・内省・関係性メモを除外し、`_extract_clean_db_theme` で人物行動傾向文をテーマとして抽出しないこと。
3. **選択肢の表記揺れ重複排除**: `TopicData.is_valid` において `_normalize_option_key`（カタカナ→ひらがな、代表的同義表記正規化）で検証し、5件未満となる表記揺れ重複を遮断すること。
4. **特定作品テーマにおける別作品キャラ混入・創作キャラの厳禁**: 作品名に合致するキャラクター・選択肢のみを抽出し、他作品混入や創作キャラ名を排除すること。
5. **問題文末尾のメタ指示文（ルール説明）残存禁止**: プロンプト禁止明記と正規表現サニタイズによる多重防御。
6. **プール内お題のカテゴリ・主題重複排除**: 同一カテゴリ（'その他'/'一般'除く）や正規化後主題キーワードのプール重複を排除すること。
7. **センシティブ・性的・怨嗟ワード排除（BAN-86）**: カタカナ卑語・性的・過激ワードをDB抽出時およびバリデーションで完全排除すること。
8. **Bot起動時・バックグラウンドLLM過剰生成抑止（BAN-118）**: 起動時プリフェッチをデフォルト無効化し、試行上限（最大6回）を制限すること。
